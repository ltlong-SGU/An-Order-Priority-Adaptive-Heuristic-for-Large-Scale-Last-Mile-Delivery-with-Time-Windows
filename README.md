# An Order-Priority Adaptive Heuristic for Large-Scale Last-Mile Delivery with Time Windows

This repository contains the empirical materials supporting the paper **“An Order-Priority Adaptive Heuristic for Large-Scale Last-Mile Delivery with Time Windows.”**

## Empirical pipeline

The accompanying research-data package contains six experimental stages:

- **E1:** Homberger 1,000-customer instance validation and descriptive analysis.
- **E2:** BIH baseline construction and strategy comparison.
- **E3:** order-difficulty scoring and validation.
- **E4:** difficulty-aware adaptive destroy-and-repair experiments.
- **E5:** BIH/ALNS improvement experiments and route-map generation.
- **E6:** consolidated statistical analysis and publication-ready results.

Each stage includes its Python implementation and the applicable tables, figures, logs, solutions, and reproducibility metadata. The package also includes the Homberger 1,000-customer benchmark archive.

## Download

Download the complete, versioned empirical package from the repository's **Releases** section. It is distributed as one ZIP archive so the full directory hierarchy and binary research artifacts are preserved.

## Integrity and reproducibility

The package includes stage-specific reproducibility manifests. After downloading, extract the archive and run the Python scripts sequentially from E1 through E6. Input and output paths are documented in the scripts.
