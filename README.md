## Empirical pipeline

The research-data package contains six experimental stages:

- **E1:** Homberger 1,000-customer instance validation and descriptive analysis.
- **E2:** BIH baseline construction and strategy comparison.
- **E3:** order-difficulty scoring and validation.
- **E4:** difficulty-aware adaptive destroy-and-repair experiments.
- **E5:** BIH/ALNS improvement experiments and route-map generation.
- **E6:** consolidated statistical analysis and publication-ready results.

Each stage includes its Python implementation and the applicable tables, figures, logs, solutions, and reproducibility metadata. The package also includes the Homberger 1,000-customer benchmark archive.

## Integrity and reproducibility

After downloading, verify the SHA-256 hash, extract the archive, and run the Python scripts sequentially from E1 through E6. Input and output paths are documented in the scripts. Stage-specific reproducibility manifests are included.
