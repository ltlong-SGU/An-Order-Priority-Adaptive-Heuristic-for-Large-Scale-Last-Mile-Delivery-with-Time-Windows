# Empirical experiments

This directory exposes the browsable source code, concise tables, and reproducibility manifests for stages E1–E6. The complete package—including all large tables, workbooks, figures, route maps, logs, solutions, and benchmark files—is available in the repository's v1.0.0 Release.

| Stage | Purpose |
|---|---|
| E1 | Dataset validation and descriptive analysis |
| E2 | BIH baseline and strategy comparison |
| E3 | Order-difficulty scoring and validation |
| E4 | Difficulty-aware adaptive destroy-and-repair |
| E5 | BIH/ALNS improvement and external comparison |
| E6 | Final synthesis, statistical tests, and publication audit |

Download the complete archive from the main README when exact binary outputs or the full directory tree are required.
